# 첫 멀티플레이 구현·검증

상태: 미검증. 기준 엔진: UE 5.8.2.

순서: Server/Client 타깃·TPP 스폰 준비 → PIE 확인 → 패키징된 2인 접속 → EOS 연동.

## 완료 기준

로컬 기반:

- 패키징된 서버 1개와 별도 클라이언트 2개가 EOS 없이 접속하고 각각 캐릭터를 소유한다.
- 양쪽에서 이동·회전·점프가 상대 창에 반영된다.
- 한 클라이언트 종료 후 다른 클라이언트는 계속 플레이하고, 종료한 클라이언트는 재접속할 수 있다.

EOS 연동:

- 서로 다른 사용자 2명이 로그인·세션 검색·참가 후 같은 서버에서 위 동작을 확인한다.
- 로그인·세션·서버 접속 실패를 구분하고 재시도할 수 있다.
- 서비스용 서버가 미인증·잘못된 인증과 로컬 개발 옵션을 통한 우회 시도를 거절한다.

PIE 성공은 패키징 검증을 대체하지 않는다. 양방향 이동은 접속 로그 외에 실제 관찰 근거를 남긴다.
결과는 [기존 기록 규칙](../Results/README.md)에 따라 작성한다.
