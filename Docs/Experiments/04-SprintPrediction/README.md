# Sprint 예측

상태: **계획 / 미구현 / 미측정**. 아래 버튼과 시나리오는 구현 예정입니다.

## 목적

클라이언트·서버의 이동 계산 불일치를 재현하고 예측·재시뮬레이션에 Sprint 입력을 반영한다.

## 예정 UI

오류 재현/개선 모드, 달리기 반복, 정상/지연/손실 프리셋, 보정 표시.

## 시나리오

오류 재현 모드는 클라이언트만 속도를 변경하는 교육용 모드로 명시한다. 개선 모드는 SavedMove 저장·복원·이동 합치기 조건을 다룬다.

## 정확성 검증

Sprint 시작·종료, 방향 전환, 점프 중 변경, 보정 후 재시뮬레이션을 확인한다.

## 측정 지표

소유 클라이언트의 보정 횟수·거리와 입력 반응. 원격 프록시의 시각적 Smoothing은 별도 평가한다.

## 재현 절차와 구현 근거

엔진 버전과 기능 구현 후 실제 버튼 순서, 조건, 클래스·함수 링크를 추가합니다.
[공통 템플릿](../TEMPLATE.md)의 항목을 따라 상세 내용을 확장합니다.

## 실제 결과와 한계

미측정. [결과 작성 규칙](../../Results/README.md)에 따라 근거 확보 후 작성합니다.
