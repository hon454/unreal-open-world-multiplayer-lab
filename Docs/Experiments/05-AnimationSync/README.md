# 애니메이션 동기화

상태: **계획 / 미구현 / 미측정**. 아래 버튼과 시나리오는 구현 예정입니다.

## 목적

진행 중인 동작을 늦게 관찰해도 현재 재생 상태를 복원한다.

## 예정 UI

동작 반복, 중간 범위 진입, 취소, 이벤트/상태 기반 비교.

## 시나리오

Action ID, Sequence ID, 서버 시작 시각, 속도, 취소 상태를 사용하는 설계를 검토한다. 지속 중인 동작 하나를 대상으로 한다.

## 정확성 검증

동작 중 진입·연속 실행·취소·재접속 시 상태를 확인한다. 이미 끝난 모든 단발 이벤트의 보존은 초기 범위가 아니다.

## 측정 지표

관찰자 간 재생 위치 차이, 시작 지연, 누락·중복·취소 처리. 게임 판정은 서버 로직에서 검증한다.

## 재현 절차와 구현 근거

엔진 버전과 기능 구현 후 실제 버튼 순서, 조건, 클래스·함수 링크를 추가합니다.
[공통 템플릿](../TEMPLATE.md)의 항목을 따라 상세 내용을 확장합니다.

## 실제 결과와 한계

미측정. [결과 작성 규칙](../../Results/README.md)에 따라 근거 확보 후 작성합니다.
