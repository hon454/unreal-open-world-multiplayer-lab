# 액터 부하

상태: **계획 / 미구현 / 미측정**. 아래 버튼과 시나리오는 구현 예정입니다.

## 목적

서버가 생성한 복제 액터 수에 따른 생성 순간·유지·변경 비용을 분리한다.

## 예정 UI

액터 +500, 초기화, 측정 시작, 측정 종료. 서버 적용 확인 후 표시를 갱신한다.

## 시나리오

500 → 2,000 → 5,000개를 하드웨어 여유에 따라 단계적으로 비교한다. 단순 액터와 스켈레탈 캐릭터의 부하를 섞지 않는다.

## 정확성 검증

초기화 후 서버·클라이언트 상태 일치, 생성·제거 수량, 실제 접속 수를 확인한다.

## 측정 지표

서버 CPU 처리 시간, 초기 복제 구간, 연결당 송신량, 메모리. 생성 프레임을 유지 구간 평균에 섞지 않는다.

## 재현 절차와 구현 근거

엔진 버전과 기능 구현 후 실제 버튼 순서, 조건, 클래스·함수 링크를 추가합니다.
[공통 템플릿](../TEMPLATE.md)의 항목을 따라 상세 내용을 확장합니다.

## 실제 결과와 한계

미측정. [결과 작성 규칙](../../Results/README.md)에 따라 근거 확보 후 작성합니다.
