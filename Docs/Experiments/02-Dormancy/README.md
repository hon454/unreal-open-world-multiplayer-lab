# Dormancy

상태: **계획 / 미구현 / 미측정**. 아래 버튼과 시나리오는 구현 예정입니다.

## 목적

변화가 드문 액터의 복제 검토 비용을 줄이되 상태 갱신의 정확성을 유지한다.

## 예정 UI

휴면 정책 On/Off, 일부 상태 변경. Off로 전환할 때 대상 액터를 깨운다.

## 시나리오

다수 자원 중 대부분은 대기하고 정해진 비율만 변경한다. 기준과 개선에서 변경 비율을 동일하게 유지한다.

## 정확성 검증

복제 상태 변경 전에 깨우기/Flush 수행, 늦은 접속·범위 복귀·동시 상호작용 후 현재 상태를 확인한다.

## 측정 지표

대기 구간 서버 복제 비용과 상태 변경 시 비용. 송신량 감소만으로 성공을 판단하지 않는다.

## 재현 절차와 구현 근거

엔진 버전과 기능 구현 후 실제 버튼 순서, 조건, 클래스·함수 링크를 추가합니다.
[공통 템플릿](../TEMPLATE.md)의 항목을 따라 상세 내용을 확장합니다.

## 실제 결과와 한계
