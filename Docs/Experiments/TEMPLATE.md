# 실험 이름

상태: 계획 / 구현 / 기능 검증 / 측정 완료 중 실제 상태를 기입합니다.

## 목적과 가설

문제, 예상 병목, 확인하려는 개선을 작성합니다.

## 엔진 원리와 구현

관련 엔진 경로, 선택한 정책, 핵심 코드 링크를 작성합니다.

## 재현 조건

엔진·프로젝트 커밋, 빌드, 장비, 실제 연결 수, 액터 수·종류, 배치, 변경 비율,
랜덤 시드, 실행 인자, 네트워크 에뮬레이션 대상·방향·값을 기록합니다.

## 조작 절차

초기화 → 부하 생성 → 안정화 → 기준 측정 → 초기화 → 동일 부하·개선 설정 → 측정.
실제 UI 버튼 이름과 성공 표시를 단계별로 작성합니다.

## 기대 결과와 정확성 검증

정상 동작, 실패 조건, 상태 일치·재진입·취소 등 회귀 검증을 작성합니다.

## 측정 방법

측정 프로세스, 지표 정의, 수집 도구, 준비·수집 시간, 반복 횟수를 명시합니다.

## 실제 결과

미측정. 수치·영상·트레이스 캡처를 확보한 뒤 채웁니다.

## 분석과 한계

가설과 결과의 차이, 비용 이전, 정확성·지연의 대가, 검증하지 못한 범위를 기록합니다.
