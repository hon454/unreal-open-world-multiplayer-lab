# Iris 공간 필터링

상태: **계획 / 미구현 / 미측정**. 아래 버튼과 시나리오는 구현 예정입니다.

## 목적

관찰자에게 필요한 액터로 연결별 복제 대상을 제한한다.

## 예정 UI

공간 필터 On/Off, 주변 밀집/월드 분산, 거점 이동.

## 시나리오

같은 총 액터 수로 플레이어 밀집·분산을 각각 비교한다. World Partition 로딩 설정은 고정한다.

## 정확성 검증

범위 이탈·재진입 시 현재 상태를 복원한다. 필터 변경으로 생긴 재전송 구간을 따로 기록한다.

## 측정 지표

연결별 대상 수, CPU, 송신량, 재진입 시 초기 상태 전달 시간.

## 재현 절차와 구현 근거

엔진 버전과 기능 구현 후 실제 버튼 순서, 조건, 클래스·함수 링크를 추가합니다.
[공통 템플릿](../TEMPLATE.md)의 항목을 따라 상세 내용을 확장합니다.

## 실제 결과와 한계

미측정. [결과 작성 규칙](../../Results/README.md)에 따라 근거 확보 후 작성합니다.
